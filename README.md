# DebugMCP Bridge for Antigravity

This simple typescript file let's you integrate the (https://github.com/microsoft/DebugMCP)[DebugMCP] plugin into your Antigravity agent. First you need to install DebugMCP via the Antigravity/VSCode Marketplace in your sidebar, then add the config from the provided example `mcp_config.json` and add it into your Antigravity config. Don't forget to change the path to the bridge script to the actual path of this project.
